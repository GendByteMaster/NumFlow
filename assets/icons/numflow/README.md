# NumFlow UI Icons

Approved Phase 6 icon assets for status and HUD surfaces.

- `power-on.svg` — NumFlow enabled
- `power-off.svg` — NumFlow disabled
- `mouse-left.svg` — left mouse button selected
- `mouse-right.svg` — right mouse button selected
- `mouse-middle.svg` — middle mouse button selected
- `drag-lock.svg` — drag/hold lock active
- `release.svg` — release/unlock action
- `precision-mode.svg` — precision mode

All icons use a transparent background and a shared cyan/blue + navy visual language. They are standalone SVG assets intended for Slint UI/HUD use.
